# AlterNative — Рентабельность договора

PWA-калькулятор экономики договора. Основная расчётная сущность — **пост**.

## Логика v1

1. Для каждого поста задаются количество постов, часы работы, график персонала и ставка сотрудника.
2. Из режима поста рассчитывается потребность в персонале.
3. Для персонала рассчитываются целевая выплата «на руки», официальный gross, доплата, обратная комиссия агента, страховые взносы, НС/ПЗ и резерв отпускных.
4. Общий персонал, ежемесячные расходы и амортизация оборудования добавляются к прямым затратам.
5. Накладные начисляются на суммарные затраты.
6. При автоматической цене расчёт gross-up'ится на УСН так, чтобы заданная прибыль осталась после УСН.
7. Итоговая цена распределяется по постам. По умолчанию — пропорционально ФОТ постов, аналогично подходу в изученной Форме-КП.
8. НДС показывается отдельно и не смешивается с выручкой без НДС.

## Графики из Формы-КП

В приложение внесены исходные параметры памятки: 16/8, 12/12, 14/10, 5/2, сутки 1/3, сутки 1/2, 2/2 по 12 часов. Для постов, работающих не 24 часа, коэффициент покрытия рассчитывается как часы работы поста / часы смены.

## Офлайн

Приложение не использует CDN. `Service Worker` кэширует все файлы. Данные расчёта хранятся локально в `localStorage`. Есть экспорт/импорт JSON.

## Важно

Налоговые ставки и параметры выплат в стартовом пресете являются **редактируемыми параметрами модели**. Это не автоматический справочник действующего законодательства.
